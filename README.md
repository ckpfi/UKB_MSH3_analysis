The purpose of these scripts is to analyze the effect of exome sequencing-derived pLOF variants in cancer susceptibility pathways (MMR and others) on cancer risk, across tumor types.
The "extract" scripts detail the extraction of high-confidence (HC) and low-confidence (LC) pLOFs from UKB.
UKB_MSH3_CK.R uses these variants to perform multivariable logistic regression analyses for cancer risk for each gene separately.
